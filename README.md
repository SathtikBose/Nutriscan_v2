# NutriScan

Scan. Understand. Eat Better.

NutriScan helps users instantly understand packaged food products by using AI to analyze ingredients, nutrition facts, additives, allergens, and overall health impact from a simple photo.

## Architecture
- **Frontend**: Android (Kotlin, Jetpack Compose, Clean Architecture)
- **Backend**: Node.js (Express, MongoDB)
- **AI Engine**: Gemini API
- **Design System**: Stitch MCP

## Project Structure
- `android/` - Android App Monorepo
- `backend/` - Node.js Express Backend
- `docs/` - Documentation
